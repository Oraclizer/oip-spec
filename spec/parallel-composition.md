# OIP v0.6 compatible service actions

This document is part of OIP v0.6.0. [Conformance scope](conformance.md) defines the requirement key words.

- The scheduler MUST classify every submitted action against the same authenticated current product state. It MUST use the actual resource footprint and identify reads of the authority epoch, execution cut, request and completion history, original event and committed publication, and current or historical observation provider. The action's declared asset alone cannot establish independence.
- Actions are eligible for exchange when their writes and the other action's reads and writes do not conflict, their shared authority and observation producers remain valid, and all earlier endpoint checks apply. Independent actions MUST preserve the same retained product state and the same reply for each action in either order. Repeated valid adjacent exchanges MUST preserve those results for finite sequences.
- The authoritative revision and exact historical prefixes and journal are shared resources. A primary action that can change them, or a policy, time, ownership, context or source-attachment change, MUST be serialized and revalidated with dependent actions. A fresh stale request is busy or rejected before effects. An exact completed retry remains bound to its own caller and full request.
- Committed secondary settlement jobs use their exact stable keys. Different job slots can be updated independently after the primary publication, target and authentication checks. Compatible observations can share the same authority with these updates. An enqueue obtains its exact key from the current committed publication, not from a caller-provided slot.
- The scheduler MUST consume the same authenticated storage boundary and actual endpoint checks on execution. Speculative footprint discovery is insufficient to authorize a write or a read. Conflicting actions use the current authority in serial order or are rejected. Physical disk offsets and commit metadata do not substitute for the product's exposed history or per-action replies.
